# Guion web

Copia de la página publicada para la Dirección de Auditoría:
**https://claude.ai/artifact/H9Cd8UmZeuzdizeh4BevY8**

Contiene todos los textos del juego con un código por bloque (`INT-01`,
`C-REV-05`…), para que se puedan pedir cambios citando el código.

- `guion.html` es la página completa (una sola, sin dependencias salvo las
  fuentes de Google).
- `img/` son las imágenes de `assets/originales/` reducidas para la web.

**Al cambiar un texto del juego, cambia también el bloque correspondiente
aquí** y vuelve a publicar la página sobre la MISMA dirección: desde una
conversación nueva, publicando con `url` igual al enlace de arriba. Si se
publica sin `url`, se crea otra página distinta y el enlace que tiene la
Dirección se queda viejo.
